! CONFIGURACIÓN ACCESS POINTS WRT300N
! ============================================================
! Para cada AP en Packet Tracer:
! 1. Conectar a puerto de switch de distribución
! 2. Abrir AP -> GUI
! 3. Setup -> Basic Setup:
!    - Configuration View: Manual
!    - Network Setup:
!      * IP Address: (según VLAN)
!        AP1: 192.168.10.2
!        AP2: 192.168.20.2
!        AP3: 192.168.30.2
!        AP4: 192.168.40.2
!        AP5: 192.168.50.2
!        AP6: 192.168.60.2
!      * Subnet Mask: 255.255.255.128
!      * Default Gateway: (IP de VLAN)
!        AP1: 192.168.10.1
!        AP2: 192.168.20.1
!        ...
!    - DHCP Server: Disable (usar servidor central)
!
! 4. Wireless -> Basic Wireless Settings:
!    - Wireless Configuration: Manual
!    - Network Mode: Mixed
!    - Network Name (SSID): ZONA-A (o la correspondiente)
!    - Channel: (ver tabla abajo)
!    - Click "Save Settings"
!
! 5. Wireless -> Wireless Security:
!    - Security Mode: WPA2 Personal
!    - Encryption: AES
!    - Passphrase: (contraseña segura)
!    - Click "Save Settings"

! VERIFICACIÓN DE LA IMPLEMENTACIÓN

!

!
! 2. Probar conectividad a gateway:

!
! 3. Probar conectividad entre VLANs:
!    ping 192.168.YY.1 (otra VLAN)
!
! 4. Probar resolución DNS:
!    ping dhcp-server.lab
!
! 5. Probar conectividad a Internet:
!    ping 8.8.8.8
!
! 6. Verificar tabla ARP:
!    arp -a
